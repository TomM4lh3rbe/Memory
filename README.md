# Memory - [Jouer en ligne](https://tomm4lh3rbe.github.io/Memory/)

Jeu de Memory : retrouve les 8 paires d'images avec le moins de coups et le moins de temps possible.

## Auteur

Tom Malherbe, BUT Informatique 2eme année, IUT de Ifs (TD JavaScript R3.01)

## Temps de travail

Environ 6 heures

## Technologies

JavaScript, Html, CSS

## Comment jouer

1. Clique sur **Lancer le jeu**.
2. Retourne deux cartes : si elles sont identiques, elles restent visibles, sinon elles se cachent.
3. Trouve les 8 paires pour gagner. Le nombre de coups et le temps s'affichent.
4. Clique sur **Rejouer** pour recommencer.

## Fonctionnalités

- Mélange Fisher-Yates
- Gestion asynchrone des tours (`setTimeout`)
- Compteur de coups et chronomètre

## Lancer en local

```bash
git clone https://github.com/TomM4lh3rbe/Memory.git
```

Ouvre ensuite `index.html` dans le navigateur.
